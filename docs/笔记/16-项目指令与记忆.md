# 16 — 项目指令与自动记忆

## 这一章做什么

三层 CLAUDE.md 加载 + @include 引用 + Token 预算防溢出。让 Rook 启动时自动读懂项目规范。

## 为什么需要

每次启动 Rook 都是"空白大脑"——不知道项目用什么技术栈、有什么规范。CLAUDE.md 是 Claude Code 的做法：把项目规范写进 Markdown 文件，Agent 启动时自动加载。

## 核心概念

- **三层加载**：项目根 `CLAUDE.md` > `.rook/CLAUDE.md` > `~/.rook/CLAUDE.md`，高优先级排前面
- **@include 引用**：`@include docs/style-guide.md` 嵌入其他文件，防环检测（visited 集合，最多 3 层）
- **注入 System Prompt**：加载后的完整文本注入 CustomInstructionsModule

## 第一步：加载

```java
// memory/ProjectInstructions.java
public static String load(Path projectRoot, Path userHome) {
    List<Path> paths = List.of(
        projectRoot.resolve("CLAUDE.md"),              // 最高优先
        projectRoot.resolve(".rook/CLAUDE.md"),
        userHome.resolve(".rook/CLAUDE.md")            // 最低优先
    );
    StringBuilder sb = new StringBuilder();
    for (Path p : paths) {
        if (Files.exists(p)) sb.append(resolve(p, projectRoot, new HashSet<>(), 0));
    }
    return sb.toString();
}
```

## 第二步：@include 递归解析

```java
// 匹配 @include <路径>
static Pattern INCLUDE = Pattern.compile("@include\\s+(\\S+)");

static String resolve(Path file, Path projectRoot, Set<Path> visited, int depth) {
    if (depth > 3 || !visited.add(file)) return "";  // 防环+防深
    if (!file.toAbsolutePath().normalize().startsWith(projectRoot)) return ""; // 安全检查
    // 递归替换 @include
}
```

## 运行验证

```bash
echo "这个项目用 Java 17，中文注释" > CLAUDE.md
cd /d D:\rook && mvnw.cmd exec:java -Dexec.mainClass=com.rook.cli.Main
```

启动后看到 `[Memory] 已加载项目指令`。问 AI "用什么语言"，回答 Java 17 + 中文注释。

## 常见坑

1. **@include 路径** — 必须相对于当前文件所在目录，且不能 `../` 跳出项目根
2. **记忆索引过大** — 超 25KB 自动截断，警告日志
3. **AutoMemory 异步失败静默** — 不影响主流程，只记日志

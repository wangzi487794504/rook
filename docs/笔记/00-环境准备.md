# 00 — 环境准备

## 这一章做什么

装好 JDK 17、Maven，配好 DeepSeek API Key，跑通第一个 Java 文件。

## 为什么需要

写代码之前先把工具链搭好。Rook 用 Java 17 + Maven + DeepSeek V4，这三样缺一不可。

## 核心概念

- **JDK 17**：LTS 版本，record/sealed/switch 表达式全支持
- **Maven Wrapper**：不装 Maven 也能编译，`mvnw` 自动下载
- **DeepSeek V4 API**：兼容 Anthropic 协议，国内直连不墙

## 第一步：装 JDK 17

去 [Adoptium](https://adoptium.net/) 下载 **OpenJDK 17 Temurin**，安装后验证：

```cmd
java --version
# openjdk 17.0.18 2026-01-20 LTS

javac --version
# javac 17.0.18
```

## 第二步：建项目目录

```
rook/
├── pom.xml
├── mvnw / mvnw.cmd
├── .mvn/wrapper/
│   ├── maven-wrapper.jar
│   └── maven-wrapper.properties
└── src/
    ├── main/java/com/rook/
    └── test/java/com/rook/
```

## 第四步：配置 Maven Wrapper

下载 `maven-wrapper.jar`：

```cmd
mkdir .mvn\wrapper
curl -L -o .mvn\wrapper\maven-wrapper.jar ^
  https://repo.maven.apache.org/maven2/org/apache/maven/wrapper/maven-wrapper/3.3.2/maven-wrapper-3.3.2.jar
```

写 `mvnw.cmd`：

```cmd
@REM Maven Wrapper startup script
set "MAVEN_PROJECTBASEDIR=%~dp0"
set "MAVEN_OPTS=-Xmx512m -Dmaven.multiModuleProjectDirectory=%MAVEN_PROJECTBASEDIR%"
set "WRAPPER_JAR=%MAVEN_PROJECTBASEDIR%\.mvn\wrapper\maven-wrapper.jar"
"%JAVA_HOME%\bin\java.exe" %MAVEN_OPTS% -classpath "%WRAPPER_JAR%" ^
  org.apache.maven.wrapper.MavenWrapperMain %*
```

## 第五步：写 Main.java

```java
// src/main/java/com/rook/cli/Main.java
package com.rook.cli;

public class Main {
    public static void main(String[] args) {
        System.out.println("Rook v0.1.0 — 终端 AI 编程助手");
    }
}
```

编译运行：

```cmd
mvnw.cmd compile
mvnw.cmd exec:java -Dexec.mainClass=com.rook.cli.Main
# 输出: Rook v0.1.0 — 终端 AI 编程助手
```

## 第六步：配 DeepSeek API Key

`config.yaml` 里用 `${ENV_VAR}` 语法引用环境变量，key 不写死在文件里：

```yaml
default_provider: deepseek

providers:
  - name: deepseek
    protocol: anthropic
    model: deepseek-v4-pro
    base_url: https://api.deepseek.com/anthropic
    api_key: ${DEEPSEEK_API_KEY}
```

终端设环境变量：

```cmd
set DEEPSEEK_API_KEY=sk-你的key
```

Rook 启动时 `ConfigLoader` 自动把 `${DEEPSEEK_API_KEY}` 替换成你设的值。也支持 `${VAR:默认值}`语法。"

## 运行验证

```cmd
mvnw.cmd compile
# BUILD SUCCESS — 环境 OK
```

## 常见坑

1. **`mvnw.cmd` 报 "系统找不到文件"** → 在 cmd 里跑不能用 bash 语法 `&&`，用 `&` 或分行写
2. **Java 版本不对** → `java --version` 一定是 17，不是的话检查 `JAVA_HOME`
3. **DeepSeek API 返回 401** → key 复制完整，去掉前后空格

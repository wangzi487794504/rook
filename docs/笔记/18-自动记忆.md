# 18 — 自动记忆：越用越懂你

## 这一章做什么

Agent Loop 每轮结束后，**异步调用 LLM** 从对话中提取用户偏好、项目知识和纠正反馈，写入四类 Markdown 笔记。

**完成后你能做到：**

- 用户说 "我喜欢简洁的回复" → 自动记住，以后都简洁
- 用户纠正 "我们项目用 Java 17 不是 21" → 自动记住，以后不犯错
- 项目里有特殊约定 → 自动记住，下次进来就知道
- AI 越用越懂你，不用每次重复说明

## 为什么需要

### 没有记忆的问题

每次启动 AI，都是一张白纸：

- 不知道你喜欢简洁还是详细
- 不知道你习惯用什么编程语言
- 不知道上次你纠正过什么错误
- 不知道项目有什么特殊约定

**每次都要重新说一遍，很烦。**

### 有记忆之后

```
第 1 次对话：
用户：我们项目所有注释都用中文
AI：好的，记住了
（自动写入记忆：项目注释用中文）

第 10 次对话：
用户：帮我写个工具类
AI：好的，注释用中文...
（自动从记忆里读取，不用用户再说）
```

**AI 越用越懂你。**

## 核心概念

### 四类笔记

|     类型      |        目录         |   内容   |                    示例                     |
| :-----------: | :-----------------: | :------: | :-----------------------------------------: |
|   **user**    |   `memory/user/`    | 用户偏好 |        "喜欢简洁回复"、"用 Java 17"         |
| **feedback**  | `memory/feedback/`  | 纠正反馈 |        "上次说错了，应该是 X 不是 Y"        |
|  **project**  |  `memory/project/`  | 项目知识 | "项目用 Maven 不是 Gradle"、"入口类是 Main" |
| **reference** | `memory/reference/` | 参考资料 |     "某个 API 的用法"、"某段代码的解释"     |

### 异步执行

- 用 `CompletableFuture.runAsync()` 在后台线程提取记忆
- 不阻塞下一轮对话
- 失败了也不影响主流程，只记日志

### LLM 去重

- 把已有记忆的标题列表给 LLM
- 让 LLM 自主决定：新增 / 更新 / 跳过
- 容错：同名文件覆盖，不会有重复

## 第一步：记忆文件格式

每条记忆是一个独立的 Markdown 文件，带 frontmatter 元数据。

```
---
name: java-17-convention
description: "项目使用 Java 17，所有注释用中文"
type: project
created: 2026-08-13T15:30:00
updated: 2026-08-13T15:30:00
source: "用户在 2026-08-13 的对话中明确说明"
---

# Java 17 约定

项目使用 Java 17，所有代码和注释都用中文。
不要建议升级到 Java 21，也不要用 Java 21 的特性。

## 具体要求
- 语言版本：Java 17
- 注释语言：中文
- 构建工具：Maven
```

### frontmatter 字段详解

|     字段      |                 含义                  |          示例          |
| :-----------: | :-----------------------------------: | :--------------------: |
|    `name`     |       记忆唯一标识，也是文件名        |  `java-17-convention`  |
| `description` |       简短描述，用于索引和去重        |   "项目使用 Java 17"   |
|    `type`     | 类型：user/feedback/project/reference |       `project`        |
|   `created`   |               创建时间                | `2026-08-13T15:30:00`  |
|   `updated`   |             最后更新时间              | `2026-08-13T15:30:00`  |
|   `source`    |               来源说明                | "用户在对话中明确说明" |

**为什么用 Markdown + frontmatter？**

- 人类可读：用户可以直接打开编辑
- 机器可解析：frontmatter 是 YAML，容易解析
- 灵活：正文可以写任意详细内容
- 版本控制友好：纯文本，git diff 清晰

## 第二步：MemoryStore — 记忆存储

负责记忆文件的读写和索引管理。

```
// memory/MemoryStore.java
package com.rook.memory;

import com.rook.llm.ChatMessage;
import org.yaml.snakeyaml.Yaml;
import java.io.IOException;
import java.nio.file.*;
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.util.*;
import java.util.stream.Collectors;

public class MemoryStore {

    private final Path memoryDir;
    private static final int MAX_INDEX_LINES = 200;
    private static final int MAX_INDEX_BYTES = 25 * 1024;  // 25KB

    public MemoryStore(Path memoryDir) {
        this.memoryDir = memoryDir;
    }

    /**
     * 保存一条记忆
     */
    public void save(MemoryNote note) throws IOException {
        Path dir = memoryDir.resolve(note.type());
        Files.createDirectories(dir);

        Path file = dir.resolve(note.name() + ".md");
        String content = formatNote(note);
        Files.writeString(file, content);

        rebuildIndex();
    }

    /**
     * 删除一条记忆
     */
    public boolean delete(String type, String name) throws IOException {
        Path file = memoryDir.resolve(type).resolve(name + ".md");
        if (Files.exists(file)) {
            Files.delete(file);
            rebuildIndex();
            return true;
        }
        return false;
    }

    /**
     * 加载所有记忆
     */
    public List<MemoryNote> loadAll() throws IOException {
        List<MemoryNote> notes = new ArrayList<>();
        for (String type : List.of("user", "feedback", "project", "reference")) {
            Path dir = memoryDir.resolve(type);
            if (!Files.exists(dir)) continue;
            try (DirectoryStream<Path> stream = Files.newDirectoryStream(dir, "*.md")) {
                for (Path file : stream) {
                    notes.add(parseNote(file));
                }
            }
        }
        return notes;
    }

    /**
     * 获取所有记忆的标题列表（用于给 LLM 去重）
     */
    public List<String> listTitles() throws IOException {
        return loadAll().stream()
            .map(n -> n.name() + " - " + n.description())
            .collect(Collectors.toList());
    }

    /**
     * 重建索引文件 MEMORY.md
     */
    public void rebuildIndex() throws IOException {
        List<MemoryNote> notes = loadAll();
        
        StringBuilder sb = new StringBuilder();
        sb.append("# MEMORY.md\n\n");
        sb.append("自动生成的记忆索引，不要手动编辑。\n\n");

        // 按类型分组
        Map<String, List<MemoryNote>> grouped = notes.stream()
            .collect(Collectors.groupingBy(MemoryNote::type));

        for (String type : List.of("user", "feedback", "project", "reference")) {
            List<MemoryNote> typeNotes = grouped.getOrDefault(type, List.of());
            if (typeNotes.isEmpty()) continue;

            sb.append("## ").append(typeName(type)).append("\n\n");
            for (MemoryNote note : typeNotes) {
                sb.append("- [")
                  .append(note.name())
                  .append("](")
                  .append(type).append("/").append(note.name()).append(".md")
                  .append(") — ")
                  .append(note.description())
                  .append("\n");
            }
            sb.append("\n");
        }

        // 检查上限
        String content = sb.toString();
        if (content.length() > MAX_INDEX_BYTES || 
            content.lines().count() > MAX_INDEX_LINES) {
            // 超过上限，只保留 description，不保留详细内容
            // 或者触发记忆压缩（用 LLM 合并相似记忆）
            System.err.println("[Memory] 索引超过上限，考虑压缩记忆");
        }

        Files.writeString(memoryDir.resolve("MEMORY.md"), content);
    }

    /**
     * 生成注入 System Prompt 的记忆摘要
     */
    public String buildSystemPromptInjection() throws IOException {
        List<MemoryNote> notes = loadAll();
        if (notes.isEmpty()) return "";

        StringBuilder sb = new StringBuilder();
        sb.append("## 记忆（从历史对话中自动提取）\n\n");

        for (MemoryNote note : notes) {
            sb.append("- **").append(note.name()).append("**: ")
              .append(note.description()).append("\n");
        }

        return sb.toString();
    }

    // ── 内部方法 ──

    private String formatNote(MemoryNote note) {
        StringBuilder sb = new StringBuilder();
        sb.append("---\n");
        sb.append("name: ").append(note.name()).append("\n");
        sb.append("description: \"").append(escapeYaml(note.description())).append("\"\n");
        sb.append("type: ").append(note.type()).append("\n");
        sb.append("created: ").append(note.created()).append("\n");
        sb.append("updated: ").append(Instant.now().toString()).append("\n");
        if (note.source() != null) {
            sb.append("source: \"").append(escapeYaml(note.source())).append("\"\n");
        }
        sb.append("---\n\n");
        sb.append("# ").append(note.title()).append("\n\n");
        sb.append(note.content()).append("\n");
        return sb.toString();
    }

    private MemoryNote parseNote(Path file) throws IOException {
        String content = Files.readString(file);
        // 解析 frontmatter
        int end = content.indexOf("---", 3);
        String yamlPart = content.substring(3, end).trim();
        String body = content.substring(end + 3).trim();

        Map<String, Object> fm = new Yaml().load(yamlPart);
        
        return new MemoryNote(
            (String) fm.get("name"),
            (String) fm.get("description"),
            (String) fm.get("type"),
            (String) fm.getOrDefault("created", Instant.now().toString()),
            (String) fm.getOrDefault("source", ""),
            extractTitle(body),
            body
        );
    }

    private String typeName(String type) {
        return switch (type) {
            case "user" -> "用户偏好";
            case "feedback" -> "纠正反馈";
            case "project" -> "项目知识";
            case "reference" -> "参考资料";
            default -> type;
        };
    }

    private String escapeYaml(String s) {
        return s.replace("\"", "\\\"");
    }

    private String extractTitle(String body) {
        // 从正文提取第一个 # 标题
        for (String line : body.lines().toList()) {
            if (line.startsWith("# ")) {
                return line.substring(2).trim();
            }
        }
        return "未命名";
    }

    // 记忆 note record
    public record MemoryNote(
        String name,
        String description,
        String type,
        String created,
        String source,
        String title,
        String content
    ) {}
}
```

- 或者按重要性排序，保留重要的

## 第三步：AutoMemory — 自动提取

从对话中自动提取记忆，异步执行。

```
// memory/AutoMemory.java
package com.rook.memory;

import com.rook.llm.ChatMessage;
import com.rook.llm.LlmProvider;
import com.rook.memory.MemoryStore.MemoryNote;
import java.io.IOException;
import java.time.Instant;
import java.util.*;
import java.util.concurrent.CompletableFuture;

public class AutoMemory {

    private final MemoryStore store;
    private final LlmProvider provider;

    public AutoMemory(MemoryStore store, LlmProvider provider) {
        this.store = store;
        this.provider = provider;
    }

    /**
     * 异步更新记忆
     * 不阻塞主流程，失败只记日志
     */
    public CompletableFuture<Void> updateAsync(List<ChatMessage> history) {
        return CompletableFuture.runAsync(() -> {
            try {
                doUpdate(history);
            } catch (Exception e) {
                System.err.println("[Memory] 自动提取失败: " + e.getMessage());
            }
        });
    }

    /**
     * 实际的记忆提取逻辑
     */
    private void doUpdate(List<ChatMessage> history) throws IOException {
        // 1. 获取已有记忆的标题列表（用于去重）
        List<String> existingTitles = store.listTitles();

        // 2. 构建 prompt
        String prompt = buildMemoryPrompt(existingTitles, history);

        // 3. 调 LLM 提取记忆
        String resp = provider.complete(List.of(
            new ChatMessage("user", prompt)
        ));

        // 4. 解析 LLM 返回的动作列表
        List<Map<String, Object>> actions = parseActions(resp);

        // 5. 执行每个动作
        for (Map<String, Object> action : actions) {
            applyAction(action);
        }
    }

    /**
     * 构建记忆提取 prompt
     */
    private String buildMemoryPrompt(List<String> existingTitles, List<ChatMessage> history) {
        StringBuilder sb = new StringBuilder();

        sb.append("你是一个记忆提取助手。请从以下对话中提取值得记住的信息。\n\n");

        sb.append("## 记忆类型\n");
        sb.append("- user: 用户偏好（喜欢什么、习惯什么）\n");
        sb.append("- feedback: 纠正反馈（用户纠正了什么错误）\n");
        sb.append("- project: 项目知识（项目的技术栈、约定、结构）\n");
        sb.append("- reference: 参考资料（有用的技术信息、API 用法）\n\n");

        sb.append("## 已有记忆\n");
        if (existingTitles.isEmpty()) {
            sb.append("（暂无）\n");
        } else {
            for (String title : existingTitles) {
                sb.append("- ").append(title).append("\n");
            }
        }
        sb.append("\n");

        sb.append("## 提取规则\n");
        sb.append("1. 只提取明确的、可复用的信息，不要提取临时内容\n");
        sb.append("2. 如果和已有记忆重复，用 update 动作更新\n");
        sb.append("3. 如果已有记忆过时了，用 delete 动作删除\n");
        sb.append("4. 新的记忆用 add 动作\n");
        sb.append("5. 不要提取隐私信息（密码、密钥等）\n\n");

        sb.append("## 输出格式\n");
        sb.append("返回 JSON 数组，每个元素是一个动作：\n");
        sb.append("```json\n");
        sb.append("[\n");
        sb.append("  {\n");
        sb.append("    \"action\": \"add\",\n");
        sb.append("    \"name\": \"java-17-convention\",\n");
        sb.append("    \"type\": \"project\",\n");
        sb.append("    \"description\": \"项目使用 Java 17\",\n");
        sb.append("    \"content\": \"项目使用 Java 17，所有注释用中文...\"\n");
        sb.append("  },\n");
        sb.append("  {\n");
        sb.append("    \"action\": \"update\",\n");
        sb.append("    \"name\": \"prefer-concise\",\n");
        sb.append("    \"content\": \"更新后的内容\"\n");
        sb.append("  },\n");
        sb.append("  {\n");
        sb.append("    \"action\": \"delete\",\n");
        sb.append("    \"name\": \"old-memory\"\n");
        sb.append("  }\n");
        sb.append("]\n");
        sb.append("```\n\n");

        sb.append("## 对话内容\n");
        sb.append("---\n");
        for (ChatMessage msg : history) {
            sb.append("[").append(msg.role()).append("]\n");
            sb.append(msg.content()).append("\n\n");
        }
        sb.append("---\n\n");

        sb.append("请提取记忆，只返回 JSON：");

        return sb.toString();
    }

    /**
     * 解析 LLM 返回的动作
     */
    private List<Map<String, Object>> parseActions(String resp) {
        // 简单的 JSON 解析
        // 实际应该用 Jackson，这里简化
        try {
            // 提取 ```json ... ``` 之间的内容
            String json = extractJson(resp);
            @SuppressWarnings("unchecked")
            List<Map<String, Object>> actions = 
                new com.fasterxml.jackson.databind.ObjectMapper()
                    .readValue(json, List.class);
            return actions;
        } catch (Exception e) {
            System.err.println("[Memory] 解析 LLM 响应失败: " + e.getMessage());
            return List.of();
        }
    }

    /**
     * 执行一个记忆动作
     */
    private void applyAction(Map<String, Object> action) throws IOException {
        String actionType = (String) action.get("action");
        String name = (String) action.get("name");

        switch (actionType) {
            case "add", "update" -> {
                String type = (String) action.getOrDefault("type", "reference");
                String description = (String) action.getOrDefault("description", name);
                String content = (String) action.getOrDefault("content", "");
                String source = (String) action.getOrDefault("source", "自动提取");

                MemoryNote note = new MemoryNote(
                    name, description, type,
                    Instant.now().toString(), source,
                    name.replace("-", " "), content
                );
                store.save(note);
                System.out.println("[Memory] " + actionType + ": " + name);
            }
            case "delete" -> {
                String type = (String) action.getOrDefault("type", "reference");
                store.delete(type, name);
                System.out.println("[Memory] delete: " + name);
            }
            default -> System.err.println("[Memory] 未知动作: " + actionType);
        }
    }

    private String extractJson(String resp) {
        // 从响应中提取 JSON 部分
        int start = resp.indexOf("[");
        int end = resp.lastIndexOf("]");
        if (start >= 0 && end > start) {
            return resp.substring(start, end + 1);
        }
        return resp;
    }
}
```

### 逐段详解

#### 1. 异步执行

```
public CompletableFuture<Void> updateAsync(List<ChatMessage> history) {
    return CompletableFuture.runAsync(() -> {
        try {
            doUpdate(history);
        } catch (Exception e) {
            System.err.println("[Memory] 自动提取失败: " + e.getMessage());
        }
    });
}
```

**为什么异步？**

- 记忆提取要调 LLM，可能要几秒
- 如果同步执行，用户要等几秒才能继续对话
- 异步执行，后台慢慢提取，不影响用户

**失败了怎么办？**

- catch 住异常，只记日志
- 不影响主流程
- 记忆提取失败了，下次还可以再提

#### 2. 构建 prompt

```
private String buildMemoryPrompt(List<String> existingTitles, List<ChatMessage> history) {
    StringBuilder sb = new StringBuilder();
    sb.append("你是一个记忆提取助手...");
    // 记忆类型说明
    // 已有记忆列表（用于去重）
    // 提取规则
    // 输出格式（JSON）
    // 对话内容
    return sb.toString();
}

**prompt 的几个关键部分：**

##### 记忆类型说明

告诉 LLM 四类记忆分别是什么，让它知道怎么分类。

##### 已有记忆列表

```
## 已有记忆
- prefer-concise - 用户偏好简洁回复
- java-17 - 用户习惯用 Java 17
```

**为什么要给已有记忆？**

- 让 LLM 去重：如果新提取的和已有的重复，就 update 而不是 add
- 让 LLM 判断过时：如果已有记忆过时了，可以 delete
- 避免创建重复记忆

##### 提取规则

```
1. 只提取明确的、可复用的信息
2. 重复的用 update
3. 过时的用 delete
4. 新的用 add
5. 不要提取隐私信息
```

##### 输出格式

明确要求返回 JSON 数组，每个元素是一个动作（add/update/delete）。

#### 3. 三种动作

|   动作   |   含义   |                场景                |
| :------: | :------: | :--------------------------------: |
|  `add`   | 新增记忆 |       发现新的值得记住的信息       |
| `update` | 更新记忆 | 和已有记忆相关，但内容有补充或修正 |
| `delete` | 删除记忆 |       已有记忆过时了或错误了       |

#### 4. 执行动作

```
private void applyAction(Map<String, Object> action) {
    String actionType = (String) action.get("action");
    switch (actionType) {
        case "add", "update" -> store.save(note);  // 保存（覆盖）
        case "delete" -> store.delete(type, name);
    }
}
```

**add 和 update 都用 save：**

- save 是覆盖写，同名文件直接覆盖
- 所以 add 和 update 实现一样
- 容错：即使 LLM 该用 update 却用了 add，也不会有重复文件

## 第四步：AgentLoop 集成

把自动记忆集成到 Agent Loop 里。

```
// core/agent/AgentLoop.java（片段）

public class AgentLoop {

    private final AutoMemory autoMemory;

    public void run() {
        while (state == LoopState.RUNNING) {
            iteration++;
            
            // 调 LLM
            StreamCollector collector = new StreamCollector(...);
            provider.stream(history, tools, collector);
            
            String text = collector.getFullText();
            List<ToolCall> toolCalls = collector.getToolCalls();
            
            if (toolCalls.isEmpty()) {
                state = COMPLETED;
                
                // ★ 自然完成（无 tool use）时触发记忆提取
                autoMemory.updateAsync(history);
                
                break;
            }
            
            // 执行工具，回灌结果...
        }
    }
}
```

### 什么时候触发记忆提取？

```
if (toolCalls.isEmpty()) {
    state = COMPLETED;
    autoMemory.updateAsync(history);  // 自然完成时触发
    break;
}
```

**只在 Agent Loop 自然完成时触发：**

- LLM 返回了最终回答，没有工具调用
- 说明这一轮任务完成了，可以提取记忆了

**为什么不在每轮都触发？**

- 太频繁，浪费 LLM 调用
- 中间轮次对话不完整，提取的记忆可能不准确
- 任务完成后，对话完整了，提取更准确

**为什么不退出时才触发？**

- 用户可能直接关窗口，来不及提取
- 每轮完成就提取，更及时

## 常见坑（详细版）

### 1. 记忆提取太频繁

**现象：** 每轮对话都提取记忆，LLM 调用很多，浪费钱。

**原因：** 在每轮 Agent Loop 结束都触发，包括中间轮次。

**解决：**

- 只在自然完成（无 tool use）时触发
- 或者加冷却时间：5 分钟内只提取一次
- 或者对话长度超过阈值才提取

### 2. LLM 去重不可靠

**现象：** 出现重复记忆，比如 `java-version` 和 `java-version-2`。

**原因：** LLM 没注意到已有记忆，或者名字起得不一样。

**解决：**

- 容错：同名文件覆盖，至少不会有完全同名的
- 已有记忆列表给得更详细（不只是标题，还有描述）
- 定期用 LLM 做记忆合并，清理重复
- 提取后做一次相似度检查，相似的合并

### 3. 异步失败静默

**现象：** 记忆没提取成功，但用户不知道。

**原因：** 异步执行，异常被 catch 了，只记日志。

**这是设计如此：**

- 记忆提取是 "锦上添花"，不是核心功能
- 失败了不应该影响对话
- 但可以在 `:memory status` 命令里显示最近的提取状态

### 4. 记忆太多，超 token

**现象：** 记忆越来越多，注入 System Prompt 后占很多 token。

**原因：** 只增不减，没有清理机制。

**解决：**

- 索引上限：200 行 / 25KB
- 超过上限触发压缩：用 LLM 合并相似记忆
- 或者按重要性排序，只注入最重要的 N 条
- 或者记忆也分层：核心记忆注入 prompt，其他记忆按需检索

### 5. 提取了不该提取的内容

**现象：** 记忆里出现了密码、密钥等敏感信息。

**原因：** LLM 没判断好什么该提取。

**解决：**

- prompt 里明确说 "不要提取隐私信息（密码、密钥等）"
- 提取后做敏感信息过滤：检测密码、密钥、token 等模式
- 用户可以手动删除不合适的记忆
- 提供 `:memory ignore <name>` 命令

### 6. 记忆过时了

**现象：** 项目已经从 Java 17 升级到 21 了，但记忆里还是 Java 17。

**原因：** 记忆只增不删，过时的信息还在。

**解决：**

- LLM 可以主动 delete 过时的记忆（prompt 里说明）
- 记忆有 updated 时间，太久没更新的可以提醒用户确认
- 用户可以手动编辑或删除记忆

### 7. LLM 返回格式不对

**现象：** LLM 返回的不是纯 JSON，有额外的文字说明，解析失败。

**原因：** LLM 喜欢加 "好的，我提取了以下记忆：" 之类的前缀。

**解决：**

- 解析时提取 `[` 到 `]` 之间的内容
- 或者要求 LLM 用 ```json 代码块包裹
- 解析失败就重试一次，或者跳过
- 用更严格的 prompt："只返回 JSON，不要任何其他文字"

### 8. 记忆文件并发写入

**现象：** 多个异步任务同时写记忆，文件损坏。

**原因：** AutoMemory 是异步的，可能同时有多个提取任务在跑。

**解决：**

- 加锁：同一时间只允许一个记忆提取任务
- 或者用队列：提取任务排队执行
- 或者保存文件时用临时文件 + 原子重命名（和 WriteFileTool 一样）
